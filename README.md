## How this was produced (and how to re-check it)

Balance of an address = sum of every `Transfer` into it minus every `Transfer` out of it, over all logs up to the snapshot block. Supply is the sum of all balances, which is then checked against `totalSupply()` read at the same block.

```solidity
// every BEP-20 transfer
topic0 = keccak256("Transfer(address,address,uint256)")
       = 0xddf252ad1be2c89b69c2b068fc378daa952ba7f163c4a11628f55a4df523b3ef
address = 0x90c8889f428F9Ebb77BB8f15CAD3a50a9aC680df
fromBlock = 44582615   toBlock = 129454096
```
Re-check any single holder on any public BSC node:

```bash
curl -s -X POST "$BSC_RPC" -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"eth_call","params":[{"to":"0x90c8889f428F9Ebb77BB8f15CAD3a50a9aC680df",
        "data":"0x70a08231000000000000000000000000ca93ec685b8623688e6b236f9068034b298c2150"},
        "0x7b75010"]}'   # balanceOf(top holder) at the snapshot block
curl -s -X POST "$BSC_RPC" -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"eth_call","params":[{"to":"0x90c8889f428F9Ebb77BB8f15CAD3a50a9aC680df",
        "data":"0x18160ddd"},"0x7b75010"]}'   # totalSupply at the snapshot block
```
Divide the returned hex by 10^18 for whole FLAPJAX. The same reads work on BscScan's contract reader at that block number.

The full scan is reproducible with `q46_holders.py` in this repository (`BSC_RPC_URL=<any public BSC node> python3 q46_holders.py`); the raw output, including every scanned chunk and all transfer logs, is in `data/`.
